II · Batch with Pillow

Python is the cleaner route — better error handling and easier to extend later. You still need Tesseract on the system, plus two Python libraries:

1. Install packages

pip install pytesseract Pillow

2. Script — save as read_screenshots.py

import os
import glob
from PIL import Image
import pytesseract

desktop_path = os.path.expanduser("~/Desktop")
if not os.path.exists(desktop_path):
    desktop_path = os.path.expanduser("~/desktop")

output_txt = os.path.join(desktop_path, "all_screenshot_text.txt")
search_pattern = os.path.join(desktop_path, "Screenshot 2026-03-04*.png")
image_files = sorted(glob.glob(search_pattern))

if not image_files:
    print("No screenshots found. Check your path or filenames.")
else:
    print(f"Found {len(image_files)} screenshots. Ripping text now...\n")
    with open(output_txt, 'w', encoding='utf-8') as outfile:
        for img_path in image_files:
            filename = os.path.basename(img_path)
            print(f"Reading: {filename}")
            outfile.write(f"\n\n{'='*50}\n  FILE: {filename}\n{'='*50}\n\n")
            try:
                img = Image.open(img_path)
                text = pytesseract.image_to_string(img)
                outfile.write(text)
            except Exception as e:
                error_msg = f"[FAILED TO READ: {e}]"
                outfile.write(error_msg)
                print(f" → {error_msg}")
    print(f"\nDone! Saved to: {output_txt}")

3. Run it

python read_screenshots.py

I · Batch OCR Methods

Comparing all approaches for extracting text from 31 desktop screenshots. Optimal method depends on privacy needs, setup tolerance, and hardware.

Option A — Online batch (no-install)

ImageToText.io: upload up to 50 images simultaneously, AI-powered, outputs .TXT. Estimate: 1–5 min for 31 images. Free for basic use. Privacy caveat: files leave your machine.

Alternatives: ImgToText.net, CardScanner.co — similar batch support.

Option B — Python + Tesseract with multiprocessing

import os
import pytesseract
from PIL import Image
from multiprocessing import Pool, cpu_count

desktop_path = os.path.expanduser('~/Desktop')
output_dir   = os.path.join(desktop_path, 'extracted_text')
os.makedirs(output_dir, exist_ok=True)

images = [f for f in os.listdir(desktop_path)
          if f.startswith('Screenshot 2026-03-04') and f.endswith('.png')]

def extract(filename):
    img_path = os.path.join(desktop_path, filename)
    text = pytesseract.image_to_string(Image.open(img_path))
    out  = os.path.join(output_dir, f"{filename[:-4]}.txt")
    with open(out, 'w') as f:
        f.write(text)
    return f"✓ {filename}"

with Pool(min(16, cpu_count())) as p:
    for r in p.map(extract, images):
        print(r)

print("Done →", output_dir)

name: Update Screenshots
on:
  schedule:
    - cron: '0 0 * * *'

jobs:
  capture:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: '3.x' }
      - run: pip install shot-scraper oxipng

          git config user.email 'actions@github.com'
          git add *.png
          git commit -m "Update screenshots" || echo "No changes"
          git push

III · Release Notes

Release notes summarize changes per version. Automating generation saves time and ensures consistency.

GitHub built-in (lowest friction)

  1. Navigate to your repo → Releases → Draft a new release
  2. Enter a tag (e.g., v1.0.0) and title
  3. Click Generate release notes
  4. Review, edit, publish

GitHub Actions automation

name: Create Release
on:
  push:
    tags: ['v*']

jobs:
  release:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4
      - uses: ncipollo/release-action@v1
        with:
          generateReleaseNotes: true
          token: ${{ secrets.GITHUB_TOKEN }}
git tag v1.0.0 && git push --tags

Third-party tools

# release-it
npm install --save-dev release-it
npx release-it

# semantic-release (uses Conventional Commits)
npm install --save-dev semantic-release
